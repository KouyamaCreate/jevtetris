# 仕様

## 目的

`/` でユーザーとJevが別々の盤面を操作する1対1のテトリス対戦を提供する。Jevは自由文生成ではなく、サーバーが列挙した合法配置から一手を選ぶ。

## 基本ルール

- 盤面は10列×20行。I / O / T / S / Z / J / Lの7種を7-bagで供給する。各bagには7種を1個ずつ入れてシャッフルし、1個ずつ配る。bagを使い切るまで次のbagを混ぜないため、同じ種類が3回連続で出ない。
- ピースは操作中も自動で落下する。レベル1は1秒に1行から始まり、10ライン消去ごとにレベルを上げ、テーブルに沿って最大50ms / 行まで速くする。
- 重力はJevの応答待ちや回転・移動の操作中も進む。一時停止中・ゲーム終了後は止まる。
- 回転はSRS形式の固定軸とwall kickを使う。JLSTZは3×3、Iは4×4の中心を軸にし、Oは対称形として見た目を変えない。壁や積み上がりに当たる回転はキック表の候補位置を順に試す。
- 接地後500msで固定する。接地中の移動・回転はロック猶予をリセットでき、上限は15回。
- 左右移動、ソフトドロップ、ハードドロップ、Holdを使える。ソフトドロップは1マスにつき1点、ハードドロップは1マスにつき2点。Holdはピース固定まで1回。
- 1 / 2 / 3 / 4ライン消去の基本点は100 / 300 / 500 / 800点で、消去時点のレベルを掛ける。
- 満行は点滅して消え、上のブロックは空いた位置へ落ちる。移動・回転・消去・ブロックの落下に演出を付け、`prefers-reduced-motion` では動きを抑える。
- Guidelineのゲームオーバー条件を、この20行表示へ次のように対応させる。新しいピースがスポーン位置のブロックと重なる場合はBlock Out、ロックしたピースのミノが1個も表示範囲へ入らない場合はLock Out、おじゃま行の挿入で既存ブロックが上端から押し出される場合はGarbage Outとして終了する。SRSの隠しバッファに相当する表示外のミノは、表示部分が残るロックでは切り捨てて次のスポーン判定へ引き継ぐ。
- 攻撃が決まったときは盤面上の大きなダメージ文字、画面全体のフラッシュと揺れを表示する。Block Out / Lock Out / Garbage Outで試合が終わったときは、盤面を覆わない試合バーへ勝敗と終了理由を表示し、盤面を見返せる状態で`Play again`から再戦できる。

重力曲線、固定時間、SRS、得点方式はテトリス各タイトルで差がある。ここでは現代的なガイドライン風の基準として、初速・レベル進行・接地猶予を実装値として定める。

## 対戦と攻撃

- ユーザーとJevは独立した10×20盤面、NEXT、HOLD、スコア、ライン、レベル、受信予定のおじゃま行を持つ。それぞれのライン数に応じた重力レベルで同時進行する。
- ユーザーは矢印キー、Z / X、Space、C / Shift、画面内のタッチ操作ボタンでプレイする。操作はJevのGateway評価を呼び出さない。
- 対戦ルールは、タイトル名だけで数値を推測しないため`guideline-battle-v1`として明示する。通常消去は1/2/3/4ライン=0/1/2/4攻撃、フルTスピンは1/2/3ライン=2/4/6、ミニTスピンは1/2ライン=1/2とする。
- RENは連続消去に対して`floor(combo / 2)`を加算し、2回目で+1、4回目で+2となる。Tetrisまたはラインを伴うTスピンの連続はB2Bとして+1し、通常のライン消去で解除する。Perfect Clearは+10とする。これらの数値はこの1対1ルールの実装値で、タイトル共通の公式表とは扱わない。
- 消したラインは1行につき保留おじゃまを1行相殺し、攻撃力がそれを上回る場合は追加分も相殺する。相殺後の攻撃だけを相手へ送る。相殺後の保留行は次のピース固定時に下から挿入し、各行には1か所の空きがある。
- 任天堂の[TETRIS 99公式解説](https://www.nintendo.com/en-gb/Games/Nintendo-Switch-download-software/TETRIS-99-1505396.html)は、4ライン消去（Tetris）、複数ライン攻撃、Tスピン、バッジによる攻撃力を説明している。[公式Tips](https://www.nintendo.com/en-gb/News/2019/March/Boost-your-block-dropping-abilities-with-our-TETRIS-99-tips--1526705.html)は2ライン以上の攻撃、連続消去のREN、受信メーターの相殺を説明している。本アプリは99人戦の標的選択・バッジ補正を含めず、ローカル1対1の明示的な攻撃表に絞る。

## Jev評価

- `/api/tetris/choose` が盤面、現在のピース位置と回転、戦略文、判断時点の `decisionContext`、相手の公開盤面を受け取り、SRSキックと下移動を含む到達可能な着地点を列挙する。現ピースを置く候補と、HOLD後の交換ピースを置く候補を同じ評価へ渡し、`play:...` / `hold:...` の原子的なChoiceにする。候補ごとに消去ライン、消したおじゃまセル、相殺量、送信量、穴・高さ、配置後の中央4列の高さ・穴・中央積みリスクを計算する。
- `decisionContext` には、盤面そのものに加えて、列ごとの高さ・最上段行・穴数、中央4列の高さ・ブロック密度・穴数、中央積みリスク（low / medium / high）、低い側へ逃がす推奨方向を含める。先頭が次に出る順のNEXT 5個、HOLD、HOLD可否、保留おじゃま行、スコア・ライン・レベル・REN・B2B、直近の技と攻撃、現在の重力間隔と次の落下までの時間、接地中のロック残時間、ロックリセット残数も含める。空中では `lockRemainingMs` を `null` とする。
- `legalMoves` の `column` / `landingRow` は表示用に1始まりとし、候補ID（`play:r{rotation}-x{x}-y{y}-...`または`hold:{piece}:r{rotation}-x{x}-y{y}-...`）を正規の識別子として扱う。Tスピン候補は最後の回転履歴も候補に保持する。
- `src/lib/jev-provider.ts`の共通アダプターから、TypeSafe公式、Vercel AI Gateway、OpenRouter、Cloudflare AI Gateway / Workers AIを選ぶ。同一評価内で`action`（実行する原子的な手）、`posture`（生存・掘り・構築・攻撃の状況）、`risk`（近い将来の危険度）を並列にChoiceする。中央4列がmedium / highの場合は、中央だけを積み上げ続けず、左右への退避またはおじゃまを掘る手を優先的に比較する。実行へ使うのは`action`だけで、補助判断を固定条件へ変換してJevの選択を上書きしない。`posture` / `risk`はJev decision欄へ表示する。
- `JEV_PROVIDER=auto`は設定済みのTypeSafe、Vercel、OpenRouter、Cloudflareの順に選び、`typesafe` / `vercel` / `openrouter` / `cloudflare`で固定できる。TypeSafeとVercelはAI SDK Evaluation API、OpenRouterはDecisions API、Cloudflareは`/ai/run`のJev入力形式を使う。キーはサーバー環境変数だけで読み、応答は内部の同じ`answers`・`usage`形式へ正規化する。
- Jevが考えている間もJevの重力は止めない。選択位置を重力が通り過ぎた場合は、現在位置から到達可能な合法手へ再計画する。操作入力は32ms間隔で適用し、応答後に到達不能な目標をそのまま追い続けない。
- 通常は1ピースごとにGateway評価を1回行う。要求中に盤面・NEXT・HOLD・おじゃま・相手公開盤面が変わった場合だけ、古い応答を捨てて同じピースを再評価する。Gateway要求は8秒で打ち切り、安全なローカル合法手へ切り替えて人間側と盤面の進行を止めない。課金対象のため、評価を始めるのはユーザーが`Start match`を押した後だけ。`Reset`は進行中のリクエストを中断し、`Pause`は盤面進行を止める。
- Gateway評価や応答検証に失敗しても試合は停止しない。現在の盤面から合法配置を列挙し、穴・高さ・凹凸・消去数で上位4候補を作り、その中から1候補を選ぶローカルフォールバックへ切り替える。フォールバック中は画面に理由を表示し、次のピースから通常評価を再開する。
- Jevの確率が70%未満または取得できない場合は、モデルの着地点を確定せず、現在のピースから選ぶ決定的な安全合法手へ切り替える。低確信度の手を待機や長いソフトドロップ列に置き換えない。Jevの手または安全な救済手について、現在の列・回転・着地行・回転履歴が一致したときだけハードドロップする。棚の下へ回り込む必要がある場合は、1行のソフトドロップ後に次の重力tickを先読みし、同じ目標へ到達できるときだけ続行する。Tスピン候補では最後の回転履歴を保持してからハードドロップする。
- 戦略はsafe / aggressive / chaosのプリセットと編集欄を持つ。1〜500文字。モデルに盤面更新を任せず、合法手以外の回答はローカル合法手へフォールバックする。
- AI Gatewayの認証情報はサーバーだけで使う。無料枠・クレジット不足・認証・レート制限・評価エラーを画面に表示し、別モデルやローカルAIへ自動で切り替えない。

## 画面と既存機能

- `/` にユーザー盤面とJev盤面、操作ボタン、NEXT / HOLD、スコアと対戦状況を表示する。Jev盤面の手前に、盤面の色とグリッドを透かして見せる半透明背景とシアンの境界を持つHUD型の判断ストリームを重ねる。HUDは「見る → 選ぶ → 動く → 固める」の進行図、現在入力、選んだ狙い、実行中の操作を分けて表示し、NEXT / HOLD / おじゃま、攻撃・相殺の狙い、posture / risk、確率とレイテンシーを人間向けの短い文で示す。HUDの情報量は維持したまま、背景とカードの透過・軽いblurでHUDと裏側の盤面を同時に読めるようにする。Gatewayの通信メトリクスは下側のテレメトリ欄へ分ける。Light / Darkを切り替えられる。
- ピースカラーはI=cyan、O=yellow、T=purple、S=green、Z=red、J=blue、L=orange。その他はニュートラル色を使う。
- 旧Decision Labは`../jev-decision-lab`へ分離し、jevtetris本体には含めない。
